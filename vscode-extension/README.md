# Ooumph AI Chat – VS Code Extension

Use the full **Ooumph AI Chat** interface (Azure DeepSeek / GPT-4o) as a native sidebar panel inside VS Code — just like GitHub Copilot or the Claude Code extension.

---

## Features

- **Sidebar panel** – opens as a dedicated Activity Bar icon
- **Panel command** – `Ctrl+Shift+O` opens a floating editor panel beside your code
- **All chat features** from the web app: streaming, chat history, skills, model picker, syntax highlighting, export
- **Credentials from VS Code settings** – no API keys hard-coded anywhere
- **API proxied through extension host** – no CORS issues

---

## Quick Start (Development)

### Prerequisites

- [Node.js](https://nodejs.org) v18+
- [VS Code](https://code.visualstudio.com) v1.85+

### 1 – Clone & enter the extension folder

```bash
git clone https://github.com/noreply-ooumph/ooumph_azure_deepseek_open.git
cd ooumph_azure_deepseek_open/vscode-extension
```

### 2 – Install dependencies

```bash
npm install
```

### 3 – Build the webview HTML

This downloads the latest web app and adapts it for VS Code:

```bash
node build.js
```

You should see:
```
✅ media/chat.html written (XXXXX bytes)
```

### 4 – Open in VS Code and run

```bash
code .
```

Press **F5** (or go to Run → Start Debugging).  
A new **Extension Development Host** window will open.

### 5 – Configure Azure credentials

In the Extension Development Host window:

1. Open **Settings** → search `ooumph`
2. Fill in:
   - **Ooumph › Azure Endpoint** – e.g. `https://YOUR_RESOURCE.openai.azure.com`
   - **Ooumph › Azure Api Key** – your Azure API key
   - **Ooumph › Models** – list of deployment names (e.g. `["DeepSeek-R1","DeepSeek-V3","gpt-4o"]`)

### 6 – Open the chat

- Click the **speech-bubble icon** in the Activity Bar (left sidebar), **OR**
- Press **Ctrl+Shift+O** (Mac: **Cmd+Shift+O**), **OR**
- Open Command Palette → **Ooumph: Open AI Chat**

## Install as a .vsix package (permanent install)

Once you are happy with the setup, you can package and install it permanently:

```bash
# Install vsce if not already installed
npm install -g @vscode/vsce

# Package the extension
vsce package

# Install it in your VS Code
code --install-extension ooumph-ai-chat-1.0.0.vsix
```

After installation the extension will appear in your Extensions list and activate on every VS Code start.

## File Structure

```
vscode-extension/
├── extension.js     ← Main extension entry point (webview host + API proxy)
├── package.json     ← Extension manifest (commands, settings, keybindings)
├── build.js         ← One-time setup script (downloads & adapts the web UI)
├── README.md        ← This file
├── .vscodeignore    ← Files excluded from the .vsix package
└── media/
    └── chat.html    ← Generated by build.js (not committed to git)
```

## How It Works

```
VS Code Extension Host
        │
        │  extension.js
        │    ├── registers sidebar WebviewViewProvider
        │    ├── registers "ooumph.openChat" command
        │    └── listens for postMessage from webview
        │              │
        │         API proxy:  fetch() in webview
        │         → postMessage → extension host
        │         → real fetch() to Azure API
        │         → stream chunks back via postMessage
        │
        ▼
   WebviewPanel / WebviewView
        └── media/chat.html  (full Ooumph UI)
               └── vscode-bridge script  (injected by extension.js)
                     ├── overrides window.fetch for Azure calls
                     ├── requests config from extension on startup
                     └── relays streaming SSE chunks to the UI
```

The original web app's code is completely unchanged.  The bridge script is injected **at runtime** into the webview HTML, so you can always re-run `node build.js` to get the latest version of the web UI.

## Updating

Pull the latest changes and re-run the build:

```bash
git pull
node build.js
```

Then reload VS Code (**Ctrl+Shift+P → Reload Window**).

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "media/chat.html is missing" error | Run `node build.js` |
| Chat shows "Azure credentials not configured" | Open Settings and fill in Ooumph credentials |
| Extension not appearing in sidebar | Reload VS Code window (Ctrl+Shift+P → Reload Window) |
| F5 doesn't start debugging | Make sure you opened the `vscode-extension` folder, not the repo root |
| Streaming not working | Check your Azure endpoint URL ends without a trailing slash |
